# 3loki Spiritual Practice

Clean Android starter project for 3loki.co.in.

## Build

Open this project in the Android IDE and run the Gradle task:

`assembleDebug`

The APK will be generated at:

`app/build/outputs/apk/debug/app-debug.apk`

This project intentionally uses the Gradle Wrapper and a standard Android Gradle Plugin setup. Do not change the Gradle version unless the IDE specifically requires it.
